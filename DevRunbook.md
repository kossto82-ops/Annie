## First-Time Setup

From the project root:

```bash
python -m pip install -e ".[dev]"
```

No database, Node.js toolchain, frontend package installation, or related local service is required. `JARVIS_LLM_*` configuration is optional; without it, Jarvis uses the deterministic keyword perceiver.

## Build

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Port 8765 is already in use | Set `JARVIS_UI_PORT` to an unused local port before running |
| Commands are launched outside the project root | Change to the project root first, or set `PYTHONPATH=./src` for a one-off run |
| Imports fail | Install the project in editable mode with `python -m pip install -e ".[dev]"` |
| Voice input/output is unavailable | Use a browser that implements the Web Speech APIs; text and face animation still work without them |
| Live LLM is not configured | This is optional; Jarvis falls back to the keyword perceiver |
| `python -m build` is unavailable | No build frontend is declared or required; install a packaging build tool only if a wheel/sdist is explicitly needed |
