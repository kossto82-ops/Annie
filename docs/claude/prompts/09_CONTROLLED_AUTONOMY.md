# JARVIS — CONTROLLED AUTONOMY

Quiero evolucionar Jarvis hacia una autonomía progresiva.

NO quiero autonomía total.

Quiero autonomía basada en confianza, riesgo y permisos.

## Levels

LEVEL 0 — Answer only
LEVEL 1 — Read information
LEVEL 2 — Reversible local actions
LEVEL 3 — Low-risk autonomous tasks
LEVEL 4 — External actions with confirmation
LEVEL 5 — Higher autonomy under explicit policy

## Decision

Para cada acción evaluar:
Risk + Permission + Confidence + Reversibility + External impact

Y decidir:
EXECUTE / ASK / REFUSE

## Principle

Más autonomía no significa mejor Jarvis.

La autonomía debe ser:
- earned
- observable
- reversible
- bounded

## Tests

Crea pruebas donde Jarvis:
- puede actuar
- debe preguntar
- debe negarse
- carece de información
- supera un límite
- intenta una acción peligrosa

No implementes autonomía abierta.
